# hyndsyght

A local-first, single-user macOS time-tracking CLI — window/AFK/media
watchers, Claude Code agent-activity tracking, and a local dashboard.

## What it does

- Tracks active window, AFK state, and media playback via a background daemon
- Tracks Claude Code agent activity (6 lifecycle hooks) via a spool-based hook entrypoint
- `hyndsyght serve` — local dashboard (Events / Attention / Ledger tabs)
- `hyndsyght mcp serve` — read-only MCP server over your tracked data

## Quick start

```bash
git clone <this repo>
cd hyndsyght
just setup
```

`just setup` runs `init` (DB + rules), installs the CLI globally on first
run, offers to install the Claude Code hooks, checks Screen Recording
permission, and offers to install + start the background daemon. Safe to
re-run — every step is idempotent.

```bash
hyndsyght status    # human-readable health check (add --json for the raw report)
hyndsyght serve     # opens the dashboard in your browser
```

## Daemon

```bash
just service-install    # symlink + bootstrap + enable the launchd agent
just service-status     # state + pid
just service-restart    # after code changes
just logs                # tail the daemon's error log
```

The launchd plist (`launchd/com.hyndsyght.daemon.plist`) is generated by
`hyndsyght setup` for your machine's paths — it's gitignored.
`launchd/com.hyndsyght.daemon.plist.example` documents its shape.

## Requirements

- macOS, Python >= 3.13, [uv](https://docs.astral.sh/uv/), [just](https://github.com/casey/just)
- Screen Recording permission (required for window-title tracking;
  `hyndsyght status` reports whether it looks granted)
- Claude Code, for agent-activity tracking
- `bun`, for the dashboard's dev build (`just web-install` / `just web-dev`)

## Repo layout

```
src/hyndsyght/
├── agentwatch/     Claude Code hook spool + ingest + reap
├── api/            FastAPI app: auth, routes, dashboard host
├── categorize/      title → category rules (TOML, hand-edited)
├── insights/       Attention Physics + Leverage Ledger computations
├── mcpserver/      read-only MCP server over the event store
├── platform/       macOS watchers (window/AFK/media) behind a Protocol seam
├── setup/          `hyndsyght setup` — hooks, daemon, wizard
├── store/          SQLite schema, connection, queries
├── cli.py          Click entry point
├── daemon.py       the one background process
├── paths.py        state-dir file locations
└── status.py       health report + human-readable rendering
web/                SvelteKit dashboard (Events / Attention / Ledger tabs)
launchd/            launchd plist template (generated + .example)
tests/              pytest, mirrors src/ layout
```
